# 崩K崩 · 新玩家规则手册

> 这是一份**给第一次玩的人**看的文档：前面是 1 分钟能看完的概括，后面是可以查的详细规则。
> 玩起来只有网页版：双击 `index.html` 即可（1 人 vs AI，可选 5 人或 8 人）。

---

# 第一部分 · 一分钟概括

## 这是个什么游戏

一圈人（网页里是 1 个你 + 几个 AI），一起喊口令、一起出手。**一回合只能做一件事：打人、挡招、或者攒气。** 被打到又没挡住就出局，最后剩一个人赢，然后全员复活开下一局。

## 三句话记住

1. **攻击要同级或更高级的防御才挡得住**：打高了破盾（对面死），打低了反噬（**你自己死**）。
2. **气是等级，不是钱**：攒一阶，一回合能做的事翻倍；但**只要有人出局，全场的气清零**。
3. **豆只杀三种人**：正在运气的人、用气功的人、用咒术之刃的人。其他人不用理它。

## 一回合的流程

```
① 选招  攻击 / 防御 / 运气（三选一）
② 喊口令  běng（拍左邻）— k（自击掌）— běng（拍左邻）— 出手！
③ 同时亮招（不许改）
④ 结算：比等级、比点数、看反弹与位移
⑤ 有人出局 → 全场气归零
⑥ 剩 1 人 → 本局结束，全员复活
```

## 新手第一局怎么打

- **0 阶（没气）**：出「刀」「枪」打人，或者出「小反弹」防身。别乱攒气。
- **想攒气**：确认场上没人盯着你、也没人会用豆的时候再按「运气」。
- **别用豆去打没在运气的人**——打了等于白打。

# 第二部分 · 详细规则

## 1. 开局与人数

| 项目 | 说明 |
| --- | --- |
| 人数 | 网页里可选 **5 人 / 8 人**（1 个你 + 4 或 7 个 AI） |
| 队形 | 一圈，你的左手边、右手边各有一名邻居 |
| 难度 | 新手 / 老手 / 高手（只影响 AI 的脑子，不影响规则） |
| 目标 | 成为圈里最后一个活着的人 |

## 2. 气与阶位（最重要）

**气 = 阶位 = 你这一回合能用的"份数"。** 攒一阶，行动力翻倍。

| 阶位 | 气值 | 一回合可用份数 | 能解锁什么 |
| --- | --- | --- | --- |
| 0 阶 | 没气 | **1 份** | 刀、枪、0 级诅咒、豆、全部 0 阶防御 |
| 1 阶 | 1 气 | **2 份** | 横扫、竖劈、冰球、火球、中反弹、1 级保佑 |
| 2 阶 | 2 气 | **4 份** | 两个 1 阶招 / 4 个 0 阶招 |
| 3 阶 | 4 气 | **8 份** | 按份数自由拼 |
| 4 阶 | 6 气 | **16 份** | **横劈**、**大反弹** |
| 5 阶 | 12 气 | 32 份 | 只是份数更多 |
| 6 阶 | 24 气 | 64 份 | 只是份数更多 |

四条铁律：

1. **运气 = 升一阶**，气不累加，只是升一格。
2. 没花完的份数**留到下一回合**（除非这一回合有人出局）。
3. 升上去**不会自己掉**，只有"有人出局"能把全场打回 0 阶。
4. **在攻击的那一回合，气的自动防御失效**（真气被牵动）。

## 3. 全部招式速查

### 3.1 攻击（按"点数"看强弱，1 点 = 一枪）

| 招式 | 阶位 | 份数 | 点数 | 说明 |
| --- | --- | --- | --- | --- |
| 刀 | 0 | 0.5 / 把 | 0.5 | 双手各一把，可合打一人，也可分打两人 |
| 枪（dia） | 0 | 1 | 1 | 两把刀打同一个人 |
| 横扫 | 1 | 2 | 1 | 扫**连续三人**（选中者当中心，左右各带一个） |
| 竖劈 | 1 | 2 | 1 | 从上往下劈，**位移躲不掉** |
| 横劈 | 4 | 16 | **16** | 最强物理 |
| 0 级诅咒 | 0 | 1 | 1 | 点名一人 |
| 1 级诅咒 | 1 | 2 | 2 | 点名一人 |
| 2 级诅咒 | 2 | 4 | 4 | 点名一人 |
| 3 级诅咒 | 3 | 8 | 8 | 点名一人 |
| 打豆豆 | 0 | 1 / 人 | 特殊 | **只杀三种状态**，可同时点两人 |
| 单豆 | 0 | 0.5 | 特殊 | 同样只杀三种状态，只能点一人 |
| 冰球 | 1 | 2 | 2 | 单点天体，被冰盾/下地克制 |
| 火球 | 1 | 2 | 2 | 单点天体，被火盾/飞天克制 |

### 3.2 防御

| 招式 | 阶位 | 份数 | 能挡什么 |
| --- | --- | --- | --- |
| 小反弹 | 0 | 1 | **同级物理**，把攻击弹回攻击者 |
| 中反弹 | 1 | 2 | 最多挡两枪的物理，同样弹回 |
| 大反弹 | 4 | 16 | **一切物理**，无限等级、无限数量，全部弹回 |
| 气功 | 0 | 1 | **无限物理全挡**，但被豆克 |
| 0/1/2/3 级保佑 | 0–3 | 1/2/4/8 | 挡对应等级的诅咒 |
| 咒术之刃 | 0 | 1 | **无限诅咒全挡**，但被豆克 |
| 冰盾 | 0 | 1 | 只挡冰球（不看等级） |
| 火盾 | 0 | 1 | 只挡火球（不看等级） |
| 飞天 | 0 | 1 | 躲：刀、枪、横扫、横劈、**火球** |
| 下地 | 0 | 1 | 躲：刀、枪、横扫、横劈、**冰球** |

> **叠加**：1 阶时可以用"两个 0 阶防御"叠在一回合里（比如 小反弹 + 冰盾）。

### 3.3 特殊

| 动作 | 效果 |
| --- | --- |
| 运气 | 升一阶，行动力翻倍 |
| 自杀 | 这回合吃到物理攻击 → **攻击者死**、自己无敌；没吃到 → **自己死** |

## 4. 判定核心

### 4.1 等级压制（盾与招）

| 攻击 vs 防御 | 结果 |
| --- | --- |
| 攻击**高于**防御 | **破盾**，防御者出局 |
| 攻击**等于**防御 | 挡住，双方无事 |
| 攻击**低于**防御 | **反噬**，攻击者出局 |

**教训：拿 0 级招去打高级防御，等于自杀。**

### 4.2 互攻：比点数

两个人同回合互指时：

- 点数**相等** → 两边的攻击互相抵消，**都不死**。
- 点数**不等** → **点数低的那一击直接作废**，点数高的照常生效。
  例：A 一枪（1 点）↔ B 一个冰球（2 点）→ A 的攻击作废，B 的冰球命中，**A 出局、B 无恙**。
- 这条只管这一对；第三方补刀照样能杀你。

### 4.3 豆系：只杀三种状态

打豆豆、单豆**对其他人完全无效**（不用防、打了也没事），只会击杀：

1. **正在运气的人**（无视等级，20 气也照杀）
2. **气功**的使用者
3. **咒术之刃**的使用者

设计意图：气功、咒术之刃是零成本万能防御，豆就是专门拆它的钉子。

### 4.4 位移：只看招式，不看等级

- 飞天躲：刀、枪、横扫、横劈、火球
- 下地躲：刀、枪、横扫、横劈、冰球
- **竖劈谁都躲不掉**（从上往下劈，飞上去钻下去都在劈的路径上）
- 飞天 + 下地可以同回合叠用，两个球一起躲

### 4.5 气的自动防御

有气的人（阶位 ≥ 2）可以**自动挡下低两级的招**，不必专门出防御：

- 物理 / 诅咒 / 天体**各有一份额度**，额度 = 阶位 − 1 点。
- 2 气：物理、诅咒、天体各能自动挡 1 点（1 枪、1 个 0 级诅咒）。
- 4 气：各 2 点（能挡一个火球，或两枪）。
- **叠超了就挡不住**：2 气吃两枪会死；但 1 枪 + 1 诅咒能同时挡下。
- **本回合在攻击 → 自动防御失效。**

### 4.6 横扫的特殊限制

- 必须扫**连续三人**：你点的那个人当中心，左右各带一名邻居。
- **不能跨过自己横扫**：你自己的左右手不能当中心（场上只剩两三人时才行）。
- 活着不足 4 人时，可以少扫几个。

## 5. 出局、复活与胜负

- 被打中又没挡住 → 出局，退出这一局。
- **只要有人出局 → 全场的气立即清零**（所以赢得越狠，全场越"散功"）。
- 圈里剩 1 人 → 本局结束，**全员复活、气归 0，开下一局**。
- 淘汰顺序就是名次：最先出局是末位，最后出局是亚军。

## 6. 新手三段路

**Lv1 · 只玩 0 阶**
只出刀、枪、小反弹。学会两件事：① 出手就没防御；② 反弹会把攻击弹回给你。

**Lv2 · 学会攒气**
在自己"安全"的回合按运气。判断安全的两条：场上没人上轮打过你 + 没人在扔豆。

**Lv3 · 学会读人**
看对方上一轮干了什么：上轮在攻击的人，这轮大概率还打 → 提前出对应防御；上轮在运气的人，这轮可以用豆点他。

## 7. 常见问题

**Q：我出了防御，为什么还是死了？**
A：三种可能——① 招式和防御**类别不对**（诅咒用物理防御挡不了）；② 对方**等级比你高**（破盾）；③ 你出的是位移，而对方用的是**竖劈**。

**Q：我攒的气怎么突然没了？**
A：这一回合有人出局了。规则是"一人出局、全场清零"，跟是谁出局无关。

**Q：我出了豆，为什么对方一点事没有？**
A：豆只杀"正在运气 / 气功 / 咒术之刃"三种状态。对方要是在出刀，豆完全无效。

**Q：我打他，为什么死的是我？**
A：三种可能——① 他出了反弹，攻击被弹回；② 你的招**等级比他防御低**（反噬）；③ 你们互攻，你的**点数比他低**，你这一击被作废、他的那一下打中了你。

**Q：为什么大家都爱打我？**
A：不会。AI 会优先打"上一轮在攻击"的人，你一直防御或运气的话，反而更少挨打。

## 8. 一页口诀

```
先看阶位再看招，同级才敢硬碰硬。
出手当回合没防御，敢砍就要敢挨打。
气是等级不是钱，一人出局全清零。
豆只杀三种人：运气、气功、咒术刃。
竖劈躲不掉，其余看位移。
互攻先比点，点低的那下作废。
```
